# Quick-menu icon concept

`companion-auto-summon-icon-preview-v1.png` is an original generated design
preview: a paw inside a clockwise circular arrow. It was created on
27 September 2026 with the built-in imagegen tool. No game artwork was supplied.

This is an opaque preview on a dark background, not a runtime texture or a
finished brand decision. Three earlier transparent attempts had visible alpha
artifacts and were rejected. This preview communicates the proposed shape;
the final asset still needs clean transparency, small-size inspection and
verified game texture loading/ownership. It is excluded from the player ZIP.
The running inert trial still uses its borrowed native companion icon.

The intended game entry opens one flat settings page. It should have no text
inside the icon; the standard selected-item caption provides the name.

## Generation prompt

Mode: built-in imagegen, new image, `transparent_background=false`.

Use case: logo-brand. A clean flat game-menu icon concept preview on a perfectly uniform solid dark charcoal background (#101820). A pure white four-toed paw centered inside a single clockwise circular arrow, communicating automatic companion summoning. Exactly six separated filled white shapes: four oval toes, one rounded paw pad, one circular arrow with an open gap on the right and a clear arrowhead. Balanced, geometric, generous negative space. Icon occupies 65 percent of a square canvas with generous margins. Crisp professional digital signage quality, completely smooth edges and flat fills. No outlines, gradients, texture, noise, speckles, glow, shadow, text, watermark, mockup frame, or extra objects. Background must remain fully opaque dark charcoal; this is only a visual design preview, not a transparent asset.
