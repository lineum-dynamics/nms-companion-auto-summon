# Nexus cover source

`nexus-cover.svg` is an original, self-contained 1600 × 900 vector cover draft
for Companion Auto Summon. It uses a dark navy/teal background, an abstract
orbital decoration, the approved title and a modest Lineum Dynamics byline.
It contains no gameplay capture, copied game/company logo, release badge or
claim about unfinished features. It has not been uploaded to Nexus.

The white glyph is reused from
[`../ui/companion-auto-summon-icon-v1.svg`](../ui/companion-auto-summon-icon-v1.svg).
Its group, geometry, fill and stroke attributes are unchanged. A local SVG
symbol and `use` instance only position and scale the existing artwork; the
decorative background is separate. No generated raster image is used.

The title remains editable text, using Segoe UI with Inter/Arial/sans-serif
fallbacks. Fonts are not embedded or downloaded. On 28 September 2026, a local
Sharp export at 1600 × 900 and a 400 × 225 thumbnail were visually inspected:
the title and icon were readable without clipping or overlap. The exported PNGs
are private preparation artifacts, not runtime files or an uploaded Nexus image.
Recheck if another renderer or fallback font is used, and verify the actual
Nexus crop when the unpublished page is created. Owner approval of this cover
has not been recorded.

This source is promotional artwork only. It is not part of the runtime icon
or game-asset staging pipeline, and it does not change the in-game glyph.
