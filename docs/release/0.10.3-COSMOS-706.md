## Next diagnostic candidate

r2 adds bounded developer diagnostics: at most 16 load callbacks and 16 matching
teleport context records per process. Log only caller RVA, check-mask bits,
Boolean argument/result predicates and whether the mapped common key is readable
and nonzero. Never log the key, pet/account IDs, pointers, save names or paths.
The context predicate, native argument/result forwarding and summon rules remain
unchanged. Owned tests cover successful and rejected diagnostic masks.

Mask bits 0..6 mean complete policy, image base, valid application, matching
receiver, applied LocalLoadState, matching vtable and stable repeated identities;
all are `0x7f`. The legacy all-zero policy has `0x80` and performs no reads.
Do not infer event semantics from a rejected guard.
