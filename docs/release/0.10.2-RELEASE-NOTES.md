# Companion Auto Summon 0.10.2-native-test

**EARLY ALPHA / Public Test.** This is the next regular update to the native
Windows/Steam build, not a separate multiplayer edition.

This update adds an experimental teleport callback candidate alongside the
existing save-load and ship-exit opportunities. An earlier build of this
candidate produced visible pets after two local teleport routes, but the exact
game meaning and remote-player behavior remain unknown. The main automation
switch and destination settings still control it, and every request continues
through the game's normal ownership, eligibility and placement checks.

The multiplayer test is specific: leave one player stationary while the other
teleports, observe both screens, then swap roles. Report whether the stationary
player's own companion appears. Turn **Automatic summoning** OFF in the in-game
menu if the behavior is disruptive. See the
[test checklist](https://github.com/lineum-dynamics/nms-companion-auto-summon/blob/main/docs/release/0.10.2-MULTIPLAYER-TEST.md)
and [current known issues](https://github.com/lineum-dynamics/nms-companion-auto-summon/blob/main/docs/KNOWN-ISSUES.md).

Death/respawn remains a separate unsupported trigger. This exact archive still
needs a fresh startup test; multiplayer behavior and Nexus scanner status are
not yet verified. Queue acceptance alone is not proof that the pet appeared.

## Compatibility and installation

- Windows 10/11 x64 and Steam only.
- Exact Steam Cosmos 7.05 / build 25624745 executable required; unknown builds
  are refused.
- Make a separate backup with the game closed before installing.
- Extract the ZIP and merge its `Binaries` and `GAMEDATA` folders into the game
  folder while NMS is closed. Do not overwrite a different `winmm.dll` that
  another mod may use.
- Start normally through Steam. Open **Quick Menu → Companions → Companion
  Auto Summon**; on PC the default Quick Menu key is X, subject to your custom
  binding. Python and pyMHF are not required.
- The exact archive passed offline validation and local ZIP readback. It was
  not started in NMS during packaging, and no second-PC or multiplayer result
  is claimed.
